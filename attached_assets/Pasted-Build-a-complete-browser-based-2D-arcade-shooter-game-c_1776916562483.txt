Build a complete browser-based 2D arcade shooter game called **"Monad Shooter"** using **vanilla JavaScript + HTML5 Canvas (NO React, NO Vite, NO build tools)** so it can run directly on **GitHub Pages**.

⚠️ IMPORTANT:

* The game MUST work as static files (index.html + game.js + assets/)
* No framework, no bundler, no TypeScript
* Must be deployable directly to GitHub Pages without build

---

🎮 GAMEPLAY

Player:

* Controlled with Arrow keys (left/right)
* Auto-shoot every 200ms
* Character name: **Chog (player ship)**

Enemies (with increasing difficulty):

1. Shramp (easy)

   * Straight down movement
   * HP: 1
   * Score: 10

2. Bob (medium)

   * Zig-zag movement
   * HP: 2
   * Score: 20

3. Moncock (hard)

   * Dash toward player
   * HP: 3
   * Score: 40

4. Emonad (BOSS)

   * Spawns every 30 seconds
   * Chases player slowly
   * Shoots bullets
   * HP: 20
   * Score: 100

---

⚡ POWER UPS (balanced, not overpowered)

Drop system:

* 15% drop chance from enemies
* 100% drop from boss

Types:

1. Shield

   * Absorbs 1 hit
   * Visual ring around player

2. Triple Shot

   * 3 bullets spread
   * Duration: 5 seconds

3. Speed Boost

   * +50% movement speed
   * Duration: 5 seconds

No stacking → picking again refreshes duration
